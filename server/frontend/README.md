# INS-EI Server Frontend

Initial web UI for the INS-EI service platform.

The frontend reads the central backend API and shows all registered INS-EI installations dynamically. It deliberately does not depend on Home Assistant/Lovelace.

Initial view:
- installation count and online/offline status
- live installation cards
- battery, PV, grid, buffer and DHW values
- last contact, sample count and optimizer action

Next: installation detail/history, customers, OekoFEN and analyses.
