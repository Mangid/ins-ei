# Changelog

## 0.9.1 — 2026-09-20
- Fixed display of existing legacy/lowercase component mappings in the component-centric UI.

## 0.9.0 — 2026-09-20
- Added Component Configuration v1.
- Added German component names and descriptions.
- Added presence configuration for optional single components.
- Added repeatable instances for HEATING_CIRCUIT, ROOM and LOAD.
- Preserved point-centric Home Assistant sensor selection.

## 0.8.x — 2026-09-20
- Reworked mappings around the INS-EI Point Catalog.
- Added grouped component/data-point view and searchable entity picker.
- Added central point descriptions, units, roles and freshness metadata.

## 0.7.x — 2026-09-20
- Added Thermal Core v1: DIRECT, BUFFER and COMBINED_STORAGE.
- Added abstract thermal components and points.
- Added thermal Discovery and measurement/parameter/status classification.
- Distinguished pellet consumption today, yesterday and total.

## 0.6.x — 2026-09-20
- Added Ingress Discovery UI and search/filter support.
- Stabilized Home Assistant Ingress UI delivery.

## 0.4.x–0.5.x — 2026-09-20
- Added persistent Ingress mapping UI.
- Connected UI mappings to the running collector.
- Added manual mapping, help metadata and Home Assistant-like presentation.

## 0.2.x–0.3.x — 2026-09-20
- Added read-only Discovery, Point Catalog, bulk import and mapping validation.
- Added automatic freshness/role defaults and duplicate checks.
- Added battery/BMS diagnostics and local Europe/Vienna log display.

## 0.1.x — 2026-09-20
- Initial Home Assistant app pilot with Supervisor API access, collector and SHADOW runtime.
